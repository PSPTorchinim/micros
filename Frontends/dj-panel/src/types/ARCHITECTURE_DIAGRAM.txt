## Data Flow - Adding New Block Type

```
STEP 1: Developer creates new component
┌────────────────────────────────────┐
│ src/components/molecules/          │
│ MyNewBlock/                        │
│   index.tsx                        │
│   MyNewBlock.tsx                   │
└────────────────────────────────────┘

STEP 2: Register in block-registry.ts
┌────────────────────────────────────┐
│ BLOCK_REGISTRY.push({              │
│   kind: 'my-new-block',           │
│   refComponent: 'my-new-block-...',│
│   refField: 'my_new_block',       │
│   strapiType: 'my-new-block'      │
│ })                                 │
└────────────────────────────────────┘

STEP 3: Register component
┌────────────────────────────────────┐
│ block-component-registry.tsx       │
│                                    │
│ 'my-new-block': MyNewBlock         │
└────────────────────────────────────┘

                ▼
    ┌───────────────────────┐
    │   AUTOMATIC MAGIC!    │
    │   No other changes    │
    │   needed anywhere     │
    └───────────────────────┘
                ▼
All infrastructure automatically handles:
• transformStrapiBlocks - transforms data
• renderBlock - renders component
• RefBlockRenderer - fetches unpopulated refs
• strapi-service - includes in populate config
```

## Request Flow Example

```
1. Strapi returns data with ref component
   { __component: 'hero-block-ref.hero-block-ref', hero_block: {...} }
                              │
                              ▼
2. transformStrapiBlocks
   • Looks up in block-registry: getBlockConfigByRefComponent()
   • Finds: { kind: 'hero-block', refField: 'hero_block' }
   • Extracts data from hero_block field
   • Returns: { __kind: 'hero-block', ...data }
                              │
                              ▼
3. renderBlock
   • Looks up in component-registry: getBlockComponent('hero-block')
   • Finds: HeroBlock component
   • Returns: <HeroBlock {...data} />
                              │
                              ▼
4. React renders HeroBlock component with data
```
